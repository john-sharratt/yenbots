# Templates

Working apps a new app starts from (`candle/docs/yenbot_app_host.md` §16),
each passing the check and using the library's art. A new app is a copy of
the closest one, under its new id, with the template's id replaced and
`guide:` set to the app-building guide's current edition.

`docs/templates.md` says what each one holds and shows; `docs/building-an-app.md`
says how to start from one.
