# Templates

Working apps a new app starts from (`candle/docs/yenbot_app_host.md` §16),
each already passing the check and using the library's art. A new app is a
copy of the closest one, under its new id, with the template's id replaced
and `guide:` set to the app-building guide's current edition.

The design's set, §16: a blank app; a list; a journal; a collection; a
planner; a tracker; an assistant; a picture maker; reminders; a daily
digest; a form and its summary.
