# The manual

One line per doc: when to read it. Read only what the task needs.

| Doc | Read it when |
|---|---|
| `../CLAUDE.md` | every session, first |
| `running.md` | releasing the binary, restarting it, or finding where it keeps its files |
| `logs.md` | anything went wrong, or you need to know what happened |
| `api/index.md` | calling the site's API — records, accounts, groups, apps, tokens, backups — from a task |

The rest of the manual — the app-building guide, the framework, calling the API from a
task step by step — arrives with the parts of the platform it describes
(`candle/docs/yenbot_app_host.md` §17, §24).
