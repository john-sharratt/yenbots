# The manual

One line per doc: when to read it. Read only what the task needs.

| Doc | Read it when |
|---|---|
| `../AGENTS.md` | every session, first |
| `building-an-app.md` | before every new app, in full, and before adding a page, a collection, a workflow or a schedule to one |
| `templates.md` | choosing the template a new app starts from |
| `manifest.md` | writing or changing an app's `app.yaml` |
| `framework.md` | writing an app's pages: its files, stores, pages, components, forms, and what every app gets — offline writes, errors reported, sign-in, settings |
| `design.md` | how an app looks: the tokens, an app's theme, the icons, every component, type — with `/_design` open beside it |
| `library.md` | an app needs a picture — a tile, a header, an empty state, a sticker — or a picture must be drawn and added |
| `data.md` | an app's fields, what a query, a sum and a search can do, and changing a collection's shape |
| `access.md` | who may use the site and see what: accounts, groups, private apps, private collections, roles, shares — and what the platform keeps safe |
| `ai.md` | an app chats with the AI, draws a picture, answers a question about its own data, or keeps a photo or a file |
| `workflows.md` | an app does something on its own — a reminder, a daily summary, a note when something changes — or a collection's fields change shape |
| `notifications.md` | an app sends a notification, someone did not get one, or the site goes on a phone's home screen |
| `integrations.md` | an app calls another service — a weather feed, a school portal — keeps a key for one, or is called by one through a hook |
| `check.md` | a change was refused, or before writing one: every rule the platform holds an app to, and what to do instead |
| `publishing.md` | making a change live, drafts and going live, releasing the platform, and undoing by failing forward |
| `zen-tasks.md` | a change bigger than a handful of an app's files, and watching a task to its end |
| `calling-the-api.md` | anything stored — records, jobs, usage, accounts — needs reading or changing: the task brief to copy |
| `api/index.md` | the API reference: every route, its parameters and answers |
| `logs.md` | anything went wrong, or you need to know what happened |
| `when-it-breaks.md` | Yen says something is wrong |
| `lifecycle.md` | exporting, importing, deleting, renaming an app, storage, backups and restoring |
| `journal.md` | before changing an app, and each time something is decided |
| `running.md` | releasing the binary, restarting it, or finding where it keeps its files |
