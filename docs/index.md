# The manual

One line per doc: when to read it. Read only what the task needs.

| Doc | Read it when |
|---|---|
| `../CLAUDE.md` | every session, first |
| `running.md` | releasing the binary, restarting it, or finding where it keeps its files |
| `logs.md` | anything went wrong, or you need to know what happened |
| `api/index.md` | calling the site's API — records, accounts, groups, apps, tokens, backups — from a task |
| `framework.md` | writing an app's pages: its files, stores, pages, components, forms, and what every app gets — offline writes, errors reported, sign-in |
| `design.md` | how an app looks: the tokens, an app's theme, the icons, every component, Vietnamese type — with `/_design` open beside it |

The rest of the manual — the app-building guide, calling the API from
a task step by step — arrives with the parts of the platform it describes
(`candle/docs/yenbot_app_host.md` §17, §24).
